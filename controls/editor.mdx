**Editor** is Nest's folder-owned file workspace. It lets you view and edit
supported documents beside an Agent conversation.

## Open Editor

1. Enable **Editor** in **Settings → Experimental** if it is currently off.
2. Use the **Chat / Editor** layout switch.
3. Select a working folder and open supported files from the workspace.

Editor tabs belong to the selected folder and are separate from an Agent's
conversation tabs. Safe Mode may block an outside-folder file until you select
its containing folder.
