---
title: "Coding Mode"
description: "Coding Mode opts an Agent into software work without changing permissions."
---

**Coding Mode** opts an Agent into software-engineering work. It does not change
the Agent's permission mode.

## Turn on Coding Mode for an Agent

Ask the Agent to do the software task. When Coding Mode is off and conversational
opt-in is available, Nest shows a **Turn on coding** review card. Approving it
enables the Agent and resumes the same request.

There is no **Turn on coding** item in the Agent's side menu. Once an Agent is
opted in, that menu can show **Turn off coding**.

**Settings → Experimental** also provides a device-wide Coding Mode override for
all Agents. Side Chats and Automations inherit the owning Agent's effective
Coding Mode.
