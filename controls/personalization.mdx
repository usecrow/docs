---
title: "Personalization"
description: "Combine account-wide preferences with a distinct personality for each Agent."
---

Turnstone has two personalization layers:

- **Settings → Personalization** holds account-wide response preferences.
- An Agent's **Personalize** tab holds that Agent's style, characteristics, and
  Additional instructions.

The current request wins over standing preferences. An Agent's own personality
is more specific than the account-wide layer.

## Ask an Agent to personalize itself

You can explicitly ask an Agent to change how it should respond in future turns.
The Agent proposes the complete updated Additional instructions in a review
card. Nothing changes until you choose **Update personality**; choosing **Not
now** leaves the profile untouched.

A one-off request such as “keep this answer short” applies only to that reply
unless you clearly ask the Agent to remember it for the future.
