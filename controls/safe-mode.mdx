title: "Safe Mode"
description: "Safe Mode is Nest's operating-system-backed filesystem boundary, separate from action permissions."
---

**Safe Mode** is Nest's operating-system-backed filesystem boundary. For
supported runs, it confines filesystem access to the selected working folder
and Nest-owned runtime paths.

Safe Mode is separate from **Read only**, **Ask first**, and **Always Allow**.
Those modes control approvals; Safe Mode controls the filesystem boundary.

## Availability

- On macOS, turn Safe Mode on or off from **Settings → Experimental** when it is
  available for the selected AI.
- Safe Mode is currently unavailable on Windows. Nest must show that state
  clearly and does not silently substitute a weaker boundary.

If the app reports Safe Mode as unavailable for the current platform or AI,
that live status is authoritative.
