An **Agent** is a named, persistent conversation. It keeps its own history,
identity, working style, Side Chats, and Automations, so you can return to the
same responsibility without rebuilding context each time.

## Work with Agents

- Choose **New Agent** to start one.
- Select an Agent in the sidebar to reopen its conversation.
- Use its menu or **Personalize** tab to rename, pin, personalize, or archive it.
- Group related Agents into a [Space](/concepts/spaces).

An Agent is the conversation itself, not a separate wrapper around a chat.

<Note>
  Some installations may still show the earlier Threads presentation while the
  Agent interface is disabled. Follow the controls currently visible in your app.
</Note>
