title: "Skills"
description: "Skills are reusable workflows you can select, install, or create with an Agent."
---

**Skills** are reusable workflows that teach an Agent how to handle a particular
kind of work consistently.

## Use and manage Skills

- Open **Skills** from the sidebar.
- Browse **Featured by Turnstone** or manage saved workflows in **Your Skills**.
- Using a featured Skill opens a new Agent with that Skill selected. It does not
  send a message automatically.
- Select a Skill for a turn when you want the Agent to follow that workflow.

## Create a Skill with an Agent

Ask the Agent to turn a repeatable workflow into a Skill. After clearly
repeatable work, an Agent may also proactively propose one Skill draft.

The proposal uses a Skill review card. Nothing is added to **Your Skills** until
you review it and choose **Save**. The Agent should tell you when it is proposing
a durable Skill rather than silently changing its behavior.
