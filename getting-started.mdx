---
title: "Getting started"
description: "Learn the basic Nest workflow: choose an Agent, add context, and review actions."
---

## 1. Open or create an Agent

Choose an existing Agent from the sidebar to continue its conversation, or
choose **New Agent** to start a persistent place for a new topic or responsibility.

## 2. Give it the right context

You can select a working folder, attach files, choose Skills, reference earlier
Nest conversations, or add a connected app with the `@` picker. When Brain is
available, the Agent can use relevant durable knowledge without making you
repeat it.

## 3. Choose the permission posture

Use **Read only**, **Ask first**, or **Always Allow** to control whether the
Agent may make changes. These permissions are separate from Safe Mode's
filesystem boundary.

## 4. Ask naturally

Describe the outcome you want. Nest can use its available tools, propose an
Automation or Skill, or show an app-owned review card when a change needs your
confirmation.

## 5. Keep related work together

Use [Spaces](/concepts/spaces) to group related Agents and
[Side Chats](/concepts/side-chats) for quick detours that should not interrupt
an Agent's main conversation.
